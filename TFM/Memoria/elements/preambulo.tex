\chapter*{Resumen}
\vspace*{-1.0cm}

Este Trabajo Fin de Máster diseña, implementa y valida una Plataforma de Gobierno del Dato orientada a gobernar metadatos técnicos y funcionales en OpenMetadata y a exportarlos conforme al perfil DCAT-AP-ES. El trabajo parte de una limitación práctica: un catálogo de publicación no demuestra por sí solo gobierno operativo, linaje técnico ni generación de metadatos desde sistemas fuente. Por ello se define un caso de uso de validación reproducible basado en un PostgreSQL de referencia, con varias tablas \texttt{gold} gobernadas en OpenMetadata y convertidas en un catálogo interoperable validado automáticamente.

La solución despliega OpenMetadata y PostgreSQL sobre Kubernetes, ingiere los activos técnicos, aplica curación funcional mediante una hoja CSV versionada y concentra la lógica en el paquete Python \texttt{om\_dcat\_sync}. Ese núcleo descubre activos, sincroniza gobierno de forma idempotente, exporta JSON-LD y ejecuta validaciones; tanto la CLI como la consola web operativa lo reutilizan sin duplicar reglas. La validación combina pruebas automatizadas del núcleo y la web, comprobación del estado vivo de OpenMetadata y validación SHACL con las \emph{shapes} oficiales DCAT-AP-ES/HVD congeladas en el repositorio. El resultado es una plataforma simple, reproducible y trazable que transforma activos técnicos gobernados en un catálogo RDF federable en ecosistemas como datos.gob.es o data.europa.eu.

\chapter*{Abstract}
\vspace*{-1.0cm}

This Master's Thesis designs, implements and validates a Data Governance Platform for governing technical and functional metadata in OpenMetadata and exporting them according to the DCAT-AP-ES profile. The work addresses a practical limitation: a publication catalogue alone does not demonstrate operational governance, technical lineage or metadata generation from source systems. For this reason, the thesis defines a reproducible validation use case based on a reference PostgreSQL database, with several governed \texttt{gold} tables in OpenMetadata converted into an automatically validated interoperable catalogue.

The solution deploys OpenMetadata and PostgreSQL on Kubernetes, ingests technical assets, applies functional curation through a versioned CSV sheet and concentrates the logic in the Python package \texttt{om\_dcat\_sync}. This core discovers assets, synchronizes governance idempotently, exports JSON-LD and runs validations; both the CLI and the operational web console reuse it without duplicating rules. Validation combines automated tests over the core and the web console, checks of OpenMetadata's live state and SHACL validation with the official DCAT-AP-ES/HVD shapes frozen in the repository. The result is a simple, reproducible and traceable platform that turns governed technical assets into a federable RDF catalogue for ecosystems such as datos.gob.es or data.europa.eu.
