\subsection{Contexto, objetivos y alcance}

\subsubsection{Enunciado oficial (resumen)}
Este Trabajo Fin de Máster propone diseñar e implementar una configuración de metadatos en OpenMetadata
alineada con DCAT-AP-ES para mejorar la interoperabilidad entre catálogos.

\subsubsection{Aclaración crítica de alcance}
Este trabajo se centra en \textbf{metadatos}, no en datos de negocio.
\begin{itemize}
  \item Los datos del caso de uso de validación son sintéticos/anonimizados.
  \item El objetivo es gobernar, mapear y exportar metadatos.
  \item La calidad evaluada es calidad de metadato (completitud/coherencia), no profiling de valores.
\end{itemize}

\subsubsection{Objetivo general (oficial)}
Diseñar y desplegar una configuración de metadatos en OpenMetadata alineada con DCAT-AP-ES para mejorar
interoperabilidad y gestión semántica de catálogos en entornos Big Data y cloud.

\subsubsection{Alcance implementado}
\begin{itemize}
  \item Despliegue reproducible de OpenMetadata en Kubernetes con Helm.
  \item Fuente técnica controlada (PostgreSQL dummy \texttt{bronze/silver/gold}).
  \item Ingesta técnica oficial (service/database/schema/table/column).
  \item Enriquecimiento de gobierno con CLI Python (\texttt{om\_dcat\_sync}).
  \item Exportación DCAT-AP-ES en JSON-LD (perfil mínimo obligatorio).
\end{itemize}

\subsubsection{Justificación del cambio de CKAN a PostgreSQL}
\begin{itemize}
  \item El objetivo inicial de cosechar metadatos desde un portal CKAN se descarta como flujo operativo porque CKAN actúa como catálogo de publicación e intercambio de metadatos ya existentes.
  \item OpenMetadata permite evidenciar mejor el ciclo de gobierno cuando parte de activos técnicos reales: servicio, base de datos, esquema, tabla y columna.
  \item PostgreSQL dummy aporta repetibilidad, control experimental y varias tablas gobernables sin depender de una instantánea externa.
  \item Desde DAMA, esta decisión refuerza gobierno, gestión de metadatos, trazabilidad, propiedad y calidad de metadatos sobre sistemas fuente.
\end{itemize}
