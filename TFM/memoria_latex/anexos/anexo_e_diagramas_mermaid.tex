\subsection*{Objetivo}
Este anexo recoge código fuente Mermaid para diagramas de arquitectura y flujo de metadatos del TFM.
Se recomienda mantener este código como fuente y exportar a SVG/PNG para la memoria final.

\subsection*{Diagrama 1 - Arquitectura lógica}
\begin{verbatim}
flowchart TB
  subgraph INFRA["Infraestructura reproducible (Kubernetes)"]
    PG[(postgres-demo)]
    OM[OpenMetadata]
    MY[(MySQL)]
    OS[(OpenSearch)]
  end

  subgraph GOV["Capa de gobierno de metadatos"]
    SYNC[om_dcat_sync<br/>(alias tfm_ingestor)]
    CFG[(YAML rules/defaults)]
  end

  PG -->|metadata ingest técnico| OM
  OM --> MY
  OM --> OS
  CFG --> SYNC
  SYNC -->|enriquecimiento| OM
\end{verbatim}

\subsection*{Diagrama 2 - Orden operativo}
\begin{verbatim}
flowchart LR
  A[1. Despliegue infra<br/>(kind + Helm)] --> B[2. Ingesta técnica<br/>PostgreSQL -> OpenMetadata]
  B --> C[3. Bootstrap gobierno<br/>(tags + custom properties)]
  C --> D[4. Enriquecimiento<br/>om_dcat_sync]
  D --> E[5. Export DCAT-AP-ES<br/>JSON-LD/RDF]
\end{verbatim}

\subsection*{Nota de conversión}
Para generar imágenes desde Mermaid (si se instala mermaid-cli):
\begin{verbatim}
npx @mermaid-js/mermaid-cli -i diagrama.mmd -o diagrama.svg
\end{verbatim}
